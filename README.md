# 🎂 Happy Birthday Komal - Birthday Wish Website

A special, romantic birthday website made with love for Komal! ❤️

## 💖 About

This is a cinematic, interactive birthday experience featuring:
- 20+ unique sections with animations
- Interactive elements (quiz, games, reveals)
- Romantic messages and shayaris
- Live counters and timelines
- Beautiful gradients and effects
- 634+ commits worth of love!

## 🚀 Tech Stack

- **React 18.3.1** - UI Framework
- **TypeScript** - Type Safety
- **Tailwind CSS v4** - Styling
- **Motion (Framer Motion)** - Animations
- **Vite** - Build Tool
- **Lucide React** - Icons

## 📦 Installation

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build
```
